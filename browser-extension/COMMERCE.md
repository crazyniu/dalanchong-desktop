# 电商页面

插件在 `manifest.json` 匹配的罗盘和百应榜单、详情页显示电商面板。面板保留商品／达人关联、销售指标、筛选、复制和批量下载；数据以当前登录账号的实际接口响应为准。

`xhr.js` 观察页面接口并创建视频列表与关联视频弹框；`commerce-ui.css` 限定这些界面的样式作用域，`content.js` 负责网页与扩展之间的消息桥。`commerce-background.js` 处理视频地址缓存、浮窗数据与下载消息。

电商面板发起的 Chrome 下载遵循对应目录与命名规则，可在浏览器下载记录中查看。插件图标弹窗负责网页媒体列表，`manager.html` 负责抖音批量解析与下载。面板、关联视频弹框与插件页面采用一致的按钮、字号和状态样式；深色标题栏、浅灰内容底与遮罩区分原网页。

封面仅用于展示，作者抖音号不作为作品 ID。点击封面与关联视频操作只使用对应条目的数据，批量复制与下载以当前选择为准。

主弹框固定标题、筛选与底部操作，列表独立滚动，分页位于列表下方。商品／达人信息及指标与关联视频分层展示；复制当前页／全部使用当前筛选结果，复制选中／下载选中保留跨页、跨筛选选择。二级弹框标明关联对象，选择数量与复制、下载只计算该对象的视频。

批量操作最多并发提交 3 个下载请求，按实际处理数量更新进度；「已提交」表示浏览器已创建任务，文件完成情况以浏览器下载记录为准。

浏览器登录状态供平台页面使用，接口权限、验证码与平台变化由真实账号使用情况决定。测试与验收由用户负责，历史隔离接口结果不能替代当前真实后台验收。
