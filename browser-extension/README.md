# 大懒虫视频插件

此目录是视频功能的唯一维护源码，由桌面端在各账号的 Google Chrome 中自动加载。每个账号使用独立的浏览器会话和扩展存储；桌面软件不提供视频入口或下载界面。开发与发布接入见 [视频插件来源](../docs/VIDEO_SOURCES.md)。

插件版本与桌面端一致，统一取自 `package.json.version`，开发启动、构建和打包时自动同步。插件资源随桌面安装包交付，各账号的浏览器数据和插件持久化存储独立保存。桌面端通过浏览器级 `Extensions.getExtensions`／`Extensions.loadUnpacked` 使用固定路径加载插件；已加载时复用，用户无需手动安装。加载与资源更新机制见 [视频插件来源](../docs/VIDEO_SOURCES.md)。

## 使用入口

- 浏览器右上角固定的插件图标打开 `popup.html`，默认查看当前网页的视频，可切换「全部视频」，选择格式、预览、复制地址或批量下载；切换范围清空选择。
- 弹窗的「批量解析」打开 `manager.html`，粘贴抖音作品链接或分享文案，每行一项；可选高清或原片，查看逐条解析结果、复制所选地址并下载所选。
- 书签栏的「视频下载」直接打开视频列表页 `manager.html#videos`，地址使用固定路径对应的实际扩展 ID，显示当前账号的媒体记录。
- 已适配的罗盘、百应等页面使用网页内电商面板，查看榜单与关联视频、筛选、复制及批量下载，范围见 [电商页面](COMMERCE.md)。


每次浏览器冷启动前补齐插件固定图标并原位更新「视频下载」书签，保留其他固定扩展与书签。重复打开已经运行的账号时只切回窗口。

列表接口带有版本标记。源码更新后，如果新打开的页面与仍在运行的后台版本不一致，列表显示「重新加载插件」；点击后重新打开弹窗。此操作会重启插件后台与下载执行页，应在现有插件下载结束后执行。

插件处理抖音作品及已适配罗盘、百应页面的视频。普通 HTTP 视频使用 Chrome 下载；HLS 点播、分轨媒体由扩展下载器处理，本地 FFmpeg WASM 负责封装。下载调度使用自动模式，扩展下载器固定 8 线程。采集结合视频字段、媒体响应和来源识别，图片、音频、接口返回及视频分段不能作为整片条目。播放器 MediaSource 缓冲、直播、加密或字节区间 HLS 不在当前下载范围。

插件弹窗、下载管理页和网页内面板沿用桌面端的中性色、深色主按钮、14px 正文与 10px 圆角。网页内面板使用独立深色标题栏、浅灰内容底和边框阴影；列表操作对应当前选择的视频，弹框通过明确按钮关闭。

管理页以视频列表为主体，顶部放链接解析，解析明细可收起，底部集中全部下载与所选操作。电商主弹框将筛选、列表、分页和批量操作分区；关联视频弹框仅操作当前商品或达人的视频。

登录或验证在来源网页完成。下载的是平台提供的文件，「原片」不保证等同于作者上传的源文件。文件保存到 Chrome 下载目录；关闭列表页面不会取消后台下载，关闭浏览器会结束当前扩展会话。

## 源码与数据

| 入口 | 职责 |
| --- | --- |
| `manifest.json`、`background.js` | 扩展权限、页面脚本、后台消息与下载调度 |
| `popup.html`、`popup.js`、`library.js` | 网页媒体列表与下载操作 |
| `manager.html`、`manager.js`、`resolve.js` | 抖音批量解析与下载列表 |
| `capture.js`、`bridge.js`、`media-records.js` | 抖音及电商页面捕获、跨脚本消息与媒体身份 |
| `media.js`、`offscreen.js`、`vendor/` | 媒体读取、分段下载与本地封装依赖 |
| `xhr.js`、`commerce-ui.css`、`content.js`、`commerce-background.js` | 电商网页面板、接口观察、消息桥与下载 |

插件列表的媒体记录、解析列表和下载任务使用 `chrome.storage.session`；电商媒体缓存、抖音详情参数及已下载 URL 历史使用 `chrome.storage.local`。浏览器负责账号 Cookie，插件按当前账号网页的登录状态请求平台。各浏览器账号的存储彼此独立，不把运行数据写入本源码目录。

修改直接在本目录进行；打包脚本生成的副本及用户运行目录不作为源码维护。测试与验收由用户负责，普通修改不运行测试、lint、构建或界面自动化。历史记录及其限制见 [HISTORY.md](HISTORY.md)，不作为当前版本验收结果。
