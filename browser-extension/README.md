# 大懒虫视频插件

此目录是视频下载功能的维护源码，可作为独立 Chrome 扩展使用；多店铺管理也会在各账号的专用 Chromium 中自动加载。每个账号使用独立的浏览器会话和扩展存储；桌面软件不提供视频下载界面；Mac 本地「视频混剪」功能见[独立说明](../docs/VIDEO_MONTAGE.md)。开发与发布接入见 [视频插件来源](../docs/VIDEO_SOURCES.md)。

插件版本与桌面端一致，统一取自 `package.json.version`，开发启动、构建和打包时自动同步。`browser-extension/` 中的维护源码必须保持可读，不得压缩、混淆或加密。打包时先复制到生成目录，仅对副本中的自有 JS 使用 esbuild 压缩空白并混淆局部标识符，禁止回写源码；不生成 source map，不附带维护文档，保留第三方声明、许可证和 LEGAL 资源，`vendor/` 保持原样。文件路径及导入保持，不使用 eval／远程脚本，不是源码加密。插件资源随桌面安装包交付，各账号的浏览器数据和插件持久化存储独立保存。桌面端通过浏览器级 `Extensions.getExtensions`／`Extensions.loadUnpacked` 使用固定路径加载插件；源码资源未变化时复用，变化时重新加载，用户无需手动安装。加载与资源更新机制见 [视频插件来源](../docs/VIDEO_SOURCES.md)。

桌面端每次打开店铺，通过 `Extensions.setStorageItems` 写入本账号的 `chrome.storage.local.shopIdentity`（编号与名称）。`shop-label.js` 在 HTTP/HTTPS 网页显示绿底白字店铺名称（背景与 Logo 同色）并监听改名，默认距左下角边缘 16px；可直接拖拽，限制在视口内并保留 8px 边距，位置仅当前网页保留，刷新后恢复默认；`shop-label-background.js` 在插件启动时为已有标签页注入，后续导航由 manifest 加载。普通浏览器未设置店铺身份时不显示标签。

## 使用入口

- 抖音 `/video/<作品 ID>`、搜索结果的视频弹层与快手视频详情页：视频实际画面右上角提供「下载原画」「下载当前清晰度」两个按钮，初始不显示文件大小；悬停、键盘聚焦某个按钮或点击下载时才读取该画质，读取时显示「读取大小…」，成功解析但没有完整文件长度时显示「大小未知」，请求失败时显示「读取失败」，悬停可查看具体原因。抖音当前作品优先读取 URL 的 `modal_id`，其次 `vid`，最后 `/video/<ID>`；切换作品或当前档位后清除对应旧大小和错误，待下一次明确操作读取；自动定位和 500 毫秒位置刷新不请求解析，下载前复核作品身份。同一作品／画质读取失败后不因反复悬停重查，点击下载会重新读取。按钮按视频原始尺寸及 `object-fit`、`object-position` 计算实际画面位置并随页面滚动，右上角离屏时隐藏，窄画面内换行。
- 详情页原画与当前清晰度下载复用完整视频检查；CDN 返回 `application/octet-stream` 等通用二进制类型时，检查 MP4 文件头识别视频。当前清晰度从同一作品、同一画质的 `url_list` 中逐个检查 CDN 地址，选用可读取的完整视频，保持作品与画质一致。
- 抖音原画使用真实 `video_id`、`ratio=default`、`source=PackSourceEnum_PUBLISH` 请求平台调度；CDN 连接失败、超时或返回 HTTP 403／404／410／5xx 时重新获取调度响应，最多请求 3 次，每次禁用 CDN 缓存，验证成功后保存最终视频地址，保持原画画质。
- 抖音当前清晰度按绑定当前视频的播放器档位识别；使用 blob／DASH 播放时，根据作品 ID、档位和画质标识匹配同档的完整 MP4，保留声音。下载前重新核对播放地址，切换画质后不复用旧地址。
- 浏览器右上角插件图标显示已捕获视频数量，点击打开弹窗，直接显示本浏览器账号全部已捕获视频，可预览、复制或下载。列表标题栏「清空」删除全部展示视频的各画质记录，与勾选无关，图标数量归零。下载任务和已下载文件保留；清空后再次播放时可重新捕获。弹窗底部「全部下载／下载所选」按全部或所选视频的每组画质直接加入后台队列；顶部「视频溯源」打开 `manager.html` 的已捕获视频列表，展示全部视频并承接所选视频；书签栏「视频下载」保留抖音批量解析入口。
- 弹窗列表点击「预览」后在当前 HTTP/HTTPS 网页中央打开播放器，不主动关闭原 popup 列表，不切换标签页或转移焦点，原列表保留选择与滚动位置。预览区默认 9:16，视频按原比例完整显示，通过「关闭」退出预览。用户点击网页后，popup 的收起遵循 Chrome 原生行为。批量管理页在本标签页中复用同一播放器。
- 抖音批量解析每行输入一个地址或分享文案，自动提取抖音长短链接并去重，优先解析原片，失败后取该作品详情中最高可用清晰度的完整视频，列表显示实际画质；批量解析与下载均在当前管理页完成，借用本浏览器已打开的抖音网页逐个请求作品，不新开、跳转或切换来源标签页；没有抖音网页时提示先打开并登录。解析后可预览、复制或下载。
- 已适配的罗盘、百应页面保留网页内电商面板，范围见 [电商页面](COMMERCE.md)。

每次浏览器冷启动前补齐插件固定图标并原位更新「视频下载」书签，保留其他固定扩展与书签。重复打开已经运行的账号时同步插件资源并切回窗口。

详情页显示「读取失败」时，更新插件并刷新详情页，按 F12 打开开发者工具，在 Console 中过滤「大懒虫视频」，开启「保留日志」后刷新并复现问题；Console 显示每次原画节点获取结果，诊断包含完整重定向链的域名、HTTP 状态和 Chrome 网络错误码。错误条目直接显示失败阶段、原因和 CDN 域名，网络失败另输出「CDN 网络错误」。复制失败、节点获取与网络错误条目用于排查。

插件监听所有 HTTP/HTTPS 网页及页面内 iframe，来源页面与视频 CDN 域名不限。页面真实请求的成功响应识别为完整视频时可加入列表；实际播放过（`!video.paused || video.played.length > 0`）、`readyState >= 2` 且有画面尺寸的播放器也可通过 HTTP(S) `video.currentSrc` 捕获并补充尺寸。不扫描未请求地址，不发额外探测请求决定入库；未取得完整文件长度时显示「大小未知」。blob 地址、音频、播放清单和视频分段不作为完整文件。同一作品的不同画质合组计数。弹窗汇总本浏览器账号所有标签页及 iframe 中已捕获的视频。popup 与管理页视频列表在标题下统一显示当前画质的实际播放地址，悬停显示完整地址，点击在新标签页打开，不区分平台；内部来源地址与捕获范围保持独立。图片、音频、接口返回和视频分段不计入数量。下载由 Chrome 原生处理。详情页与批量解析页的任务由 `library.js` 后台队列管理，整批一次入队，最多同时处理 6 个完整视频文件；准备中的文件占用并发名额，各文件的完整性检查与下载独立进行，单个文件检查较慢不阻塞其他名额，完成或失败立即补入下一项。进度与任务状态保存在扩展会话存储中，后台休眠后可恢复调度。图片、音频、接口返回及视频分段不能作为整片条目。

下载管理页和网页内面板沿用桌面端的中性色、深色主按钮、14px 正文与 10px 圆角。网页内面板使用独立深色标题栏、浅灰内容底和边框阴影；列表操作对应当前选择的视频，弹框通过明确按钮关闭。

管理页使用浅灰底、白色内容区和深灰主按钮；逐行地址输入框提示「粘贴抖音地址或分享文案，每行一个」，后接「下载的视频就是溯源的原视频。」；下方显示链接数量，右侧放「解析」。视频列表表头仅保留数量与清空，解析明细可收起，失败时自动展开并显示完整原因，底部集中下载操作；新解析结果不自动勾选，默认显示「全部下载」，手动勾选后显示「下载所选」。电商主弹框将筛选、列表、分页和批量操作分区；关联视频弹框仅操作当前商品或达人的视频。

登录或验证在来源网页完成。下载的是平台提供的文件，不保证等同于作者上传的源文件。详情页原画按钮保持原有解析规则；批量解析使用其他可用画质时按实际画质显示，不标成原画。文件保存到 Chrome 下载目录；关闭列表页面不会取消后台下载，关闭浏览器会结束当前扩展会话。

## 源码与数据

| 入口 | 职责 |
| --- | --- |
| `manifest.json`、`background.js` | 扩展权限、页面脚本、后台消息与下载调度 |
| `library.js` | 媒体记录、数量角标与下载调度 |
| `messages.js` | 校验自身扩展消息的 sender 与类型，转发异步处理结果 |
| `capture.js`、`capture-background.js` | 监听所有 HTTP/HTTPS 网页及 iframe 的完整视频成功响应与已播放且解码成功的 currentSrc，保留顶层标签页归属 |
| `popup.html`、`popup.js`、`popup.css` | 插件图标弹窗、全部已捕获视频、直接批量下载与管理页入口 |
| `detail-buttons.js`、`detail-page.js` | 详情页播放器按钮与当前视频地址 |
| `preview-background.js`、`preview.html`、`preview.js`、`preview.css` | popup 发起的网页中央预览；扩展 iframe 显示不自动聚焦的普通面板，原列表不主动关闭 |
| `player.js`、`player.css` | 网页预览与管理页共用的播放器、加载反馈与显式关闭 |
| `manager.html`、`manager.js`、`resolve.js` | 抖音批量解析、已捕获视频与下载列表 |
| `media-records.js` | HTTP/HTTPS 媒体来源、作品身份、格式分组与文件命名 |
| `media.js`、`vendor/ui/`、`vendor/icons/` | 完整视频检查、管理页组件与图标 |
| `xhr.js`、`commerce-ui.css`、`content.js`、`commerce-background.js` | 电商网页面板、接口观察、消息桥与下载 |

通用捕获记录的 `sourceTabIds` 保存发现同一媒体的全部顶层标签页 ID，供内部来源归属使用；`sourceTabId` 与 `sourceUrl` 保留记录的来源标签页和链接。相同媒体地址跨页捕获时合并归属，不覆盖其他页的记录。插件列表的媒体记录、解析列表和下载任务使用 `chrome.storage.session`；电商媒体缓存、抖音详情参数及已下载 URL 历史使用 `chrome.storage.local`。浏览器负责账号 Cookie，插件按当前账号网页的登录状态请求平台。各浏览器账号的存储彼此独立，不把运行数据写入本源码目录。

修改直接在本目录进行；打包脚本生成的副本及用户运行目录不作为源码维护。测试与验收由用户负责，普通修改不运行测试、lint、构建或界面自动化。历史记录及其限制见 [HISTORY.md](HISTORY.md)，不作为当前版本验收结果。
