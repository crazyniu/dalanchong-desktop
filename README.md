## 在线更新

侧栏左上角在「大懒虫」名称下显示版本号，点击查看软件更新；左下角以无底色单行文字显示授权到期日期，点击查看激活信息。授权正常为次要文字色，剩余 7 天内改为琥珀色，已到期为红色。每次启动自动读取 Gitee 发布的 Tauri 更新元数据，发现新版后弹出升级提示和 Markdown 更新说明；同次运行关闭后不重复提示相同版本。点击「立即更新」后显示下载进度，下载并验签成功后自动安装、重启，无需手动打开安装包。更新期间不启动新任务，已有采集或邀约正常结束后再安装；安装前保存账号、Cookie 与运行记录，失败后可点击重试。Windows 安装过程只显示进度，不需要逐步点击安装。

`run.sh` 源码模式可以检查版本，下载安装由正式安装版提供；第一次安装需要使用发布的 DMG/NSIS 安装包。打包、发布与版本检查见 [发布说明](docs/RELEASE.md)。

## 运行

一键启动桌面端：

```sh
sh ./run.sh
```

脚本自动安装依赖并启动 Tauri/Vite。需要 Node 24、pnpm 11、Rust 1.94+；macOS 还需 Xcode Command Line Tools。Mac 支持 Apple 芯片 arm64，macOS 最低 14；Windows 支持 x64，使用系统 WebView2。相对本仓库，日常数据目录为 `../.local/ecommerce-assistant/`，可通过 `ASSISTANT_TEST_DATA` 指定隔离目录；未指定时会使用真实本机账号数据。

只预览 Web 界面：

```sh
pnpm install
pnpm dev
```

打开 [本机 Web 预览](http://127.0.0.1:5173) 查看界面。浏览器内使用演示账号和演示数据，点击「开始邀约」仅模拟任务，不发送真实邀约。

Tauri 版先输入激活码，再使用真实平台网页与独立账号会话，首次启动没有演示账号。从侧栏进入「抖音达人邀约」或「快手达人邀约」并添加对应平台账号，通过独立浏览器弹窗登录；平台接口确认身份后保存会话、关闭登录弹窗，并更新账号列表。已登录账号的「打开」保留浏览器窗口。

`pnpm desktop` 和 `pnpm desktop:dev` 均启动 Tauri 开发模式，端口 1420；使用系统应用数据目录时可直接运行这两个命令。

## 激活

在激活码后台选择「大懒虫」（`app_id: dalanchong`）创建激活码，输入桌面端即可。激活页面显示可复制的设备码；激活后左下角授权入口只显示到期时间和设备码。换机先在后台解绑，原到期时间不变。

设备码由 Rust 从系统硬件 UUID 生成 `hw-v1-<SHA-256>` 中间字符串，再取 MD5 得到 32 位小写十六进制；界面显示、复制和授权请求共用此设备码，只上传摘要。每次启动重新读取硬件，修改缓存或复制配置不能替换设备码；同一电脑重装软件、清缓存后保持一致。同一个激活码只能绑定一台设备，已绑定后拒绝其他设备激活或使用。

Rust 后台启动时查询一次授权，此后每 10 分钟查询一次；弹框、业务操作和平台请求只使用最近结果，不发起额外校验。后台返回联网失败、过期、解绑或设备不符后，停止采集、邀约并显示激活页；保存过激活码时继续按 10 分钟间隔查询。管理员账号只用于激活码后台，不用于桌面端。

使用与接入细节见 [激活说明](docs/ACTIVATION.md)。

## 功能

- 使用教程：侧栏「使用教程」提供操作步骤、常见问题与支持采集页面入口，可点击「重播新手引导」从第一步重新查看。授权与初始化完成后，首次且没有运行任务时自动显示引导；关闭、稍后再看或完成后不再自动弹出，仍可手动重播。
- 多店铺：使用本机正常安装的 Google Chrome Stable。新建店铺并设置名称，卡片显示名称、最近打开时间和打开、编辑、删除操作；各店铺分别保存登录、标签页、收藏和插件数据。重复打开切回同一窗口，冷启动恢复会话。网页使用 Chrome 原生 UA、语言、时区、硬件与音视频能力。未安装 Chrome 时可前往 [Google 中国官方下载页](https://www.google.cn/chrome/) 安装，详见 [多店铺](docs/BROWSER.md)。达人采集与邀约使用独立 WebView 会话。
- 多店铺视频功能：打开店铺后自动加载插件，右上角固定图标和「视频下载」书签提供入口。抖音视频列表、批量复制、批量下载及罗盘、百应面板由 Chrome 视频插件提供，视觉与桌面端保持一致；软件页面不设置视频入口或下载界面。功能只维护 [插件源码](docs/VIDEO_SOURCES.md)，各账号的扩展数据独立保存。
- 数据概览：平台、账号、日期筛选，采集与邀约统计、趋势、结果分布、账号剩余额度、CSV 导出。额度取自平台网页被动观察到的响应，仅供查看。「已采集达人」统计当前保留列表中符合账号范围及采集日期的达人；邀约指标按筛选日期内真实记录的状态计数，结果分布只展示成功、跳过、失败和待核实，环形图中心总记录为这四种结果之和。详细统计口径见 [DESIGN.md](DESIGN.md)。
- 达人邀约：侧栏分别提供「抖音达人邀约」「快手达人邀约」入口，菜单统一使用单色线框图标，进入对应平台工作区并独立高亮；页面顶部直接显示账号 Tab。采集限定快手三个、抖音四个指定页面，采集前在平台原网页设置搜索和筛选，再沿用当前页面条件采集；页面清单见下方[当前平台适配范围](#当前平台适配范围)。抖音邀约时检查权限和商品可带范围，再发送首次邀约卡片。两平台都先将采集结果保存到采集列表。
- 账号 Tab：邀约页每个账号对应一个浏览器 Tab，旁边的「＋」添加当前平台账号，Tab 上的「×」确认删除，右键菜单提供编辑名称与删除。运行任务的账号不可删除；名称保存为本地备注，平台身份不变。切换 Tab 保留独立网页与登录会话；悬浮工具栏操作当前 Tab，按住左侧六点图标可在网页内移动；「主页」回到当前账号所属平台的默认达人页面，前进、后退图标操作该账号网页的浏览历史，采集或邀约运行时禁用；邀约弹框默认使用当前账号。
- 采集列表：在弹框中显示当前账号独立保存的达人和邀约状态，最新采集在前；主要信息按达人与最近邀约、粉丝、销售数据和采集信息排序，CSV 使用相同字段顺序。快手可选列为近 30 日及近 7 日合作销售额，抖音为近 30 日销售额及结算额；可选列仅在当前账号全部采集记录中至少有一条有效值时显示，不随分页或列表筛选变化。达人、邀约状态、粉丝、采集来源、采集时间与操作列保留。缺失值显示「—」，数字 0 正常保留，平台金额区间按区间展示，重新采集补齐已有记录。支持横向滚动，固定达人和操作列，点击「查看」使用系统默认浏览器打开达人主页，并保留列表弹框；支持按达人姓名、ID、店铺名称／来源搜索，忽略首尾空格及英文大小写；抖音达人列显示头像与昵称，可一键复制昵称；快手显示并复制快手号。达人 ID 继续用于检索和 CSV 导出，采集来源显示简洁的来源名称或真实店铺名。工具行保留搜索、筛选按钮与业务操作；独立筛选弹框提供邀约状态、达人性别（全部、男、女、未知）、精确粉丝上下限与采集来源，来源选项取自当前账号实际记录，无可选来源时隐藏该下拉。支持应用、重置、取消及跨页勾选。未勾选时可从当前账号跨页筛选结果中批量邀约无邀约记录的达人、导出筛选结果或删除当前账号全部达人；勾选后切换为邀约、导出或删除所选达人，邀约所选同样先排除已有邀约记录者。列表不显示账号筛选或每行账号名称。
- 列表分页：采集列表、邀约记录和错误日志由本地数据库查询当前页，支持每页 10、20、50、100 条，并可输入页码跳转。
- 采集记录：采集时在网页右下角、底部工具栏上方显示可收起的半透明深色终端，包含时间、逐条达人名称及新增／更新结果、页数汇总和完成或停止信息；抖音同行合作参考的进度标明店铺名称、该店合作达人页码与已采集达人总数。每账号独立，切换 Tab 跟随；上滚查看旧记录时不会被新记录拉回底部。正常采集记录保存到本地数据库，终端只展示当前采集任务最近 200 条；错误日志界面仍只显示异常。
- 错误日志：只记录异常，保留账号、步骤、接口、HTTP 状态、业务码、请求 ID 和脱敏响应正文；达人邀约页及账号管理弹框只展示当前账号，保留时间、内容、详情、分页、导出和清空，不显示平台、账号筛选或账号、类型列。无账号时账号管理中的日志入口禁用。
- 邀约设置：点击「批量邀约」或「邀约所选」后，使用当前账号填写商品 ID、话术、联系方式与间隔。间隔只限定同账号两次正式发送的开始时间，快手最低 2000 毫秒、抖音最低 500 毫秒；首条在必要准备完成后立即发送，检查、响应和保存耗时计入间隔，跳过达人不消耗间隔。最大邀约数只在邀约弹框设置，两平台每次新建邀约均默认留空、不限人数，不沿用上次人数；可手动填写本次上限，进入登录再返回时保留本次填写。记录支持筛选、详情、导出、清空和人工核实。
- 邀约记录详情：每行提供「达人主页」按钮和详情入口，两平台主页均在系统默认浏览器打开，保留当前弹框、账号网页与任务；抖音缺少可用 UID 时禁用主页按钮。详情的达人信息显示名称，ID 保留用于匹配、检索与导出。两平台详情底部均提供「接口返回」，显示成功或失败时实际保存的响应；没有保存数据时显示「暂无接口返回记录」。响应隐藏敏感字段，正文最多保留 8000 字符，成功记录保存在邀约历史中。邀约详情与错误日志详情均格式化显示 JSON，非 JSON 或已截断正文保持原样，可一键复制实际保存的接口信息与正文，并提示复制结果。
- 邀约进度：主窗口右下角的全局状态卡汇总快手、抖音全部运行中任务的已邀约、跳过、失败和待核实数量，可按账号停止任务。卡片固定在默认底部工具栏上方；切换左侧菜单、平台、账号、开关任意弹框或菜单，以及拖动工具栏时，保持相对主窗口的位置不变。任务继续执行，卡片持续可见，只有全部任务完成或停止后才隐藏；邀约状态优先于采集终端。
- 任务操作保护：仅采集执行时，对应账号网页显示 15% 深色遮罩并禁用网页交互，遮罩没有中心标签，采集结束或停止后恢复。邀约期间不加任务遮罩，网页可交互；工具栏、采集记录、进度卡与停止按钮保持可用。
- 账号管理：达人邀约页在当前平台无账号时显示添加入口，账号 Tab 右侧打开当前平台的管理弹框，可添加、编辑备注、打开、重新登录和删除账号。在达人邀约页从 Tab、空状态或管理弹框添加账号后，关闭添加与管理弹框、选中新账号 Tab，并在该账号网页打开对应平台登录页。抖音在账号页登录成功后自动进入达人广场；后续身份刷新不打断浏览或后退。数据概览中新增账号，以及账号管理手动「打开」「登录」「重新登录」，使用独立浏览器弹窗，与该账号邀约网页共用持久会话。两平台的账号、配置和任务分别保存，切换平台或账号保留会话与任务；编辑备注同步更新账号名称，平台真实店名和 ID 独立保留。

先在指定采集页面完成搜索和筛选，取得当前页列表响应后点击「开始采集」，采集结果逐批保存；采集结束或停止都不会发送邀约。点击工具栏的「邀约达人」打开「采集列表」弹框，点击「批量邀约」使用当前账号的跨页筛选范围，或勾选后点击「邀约所选」使用已选范围，确认当前账号已登录，填写配置后明确点击「开始邀约」。邀约前先排除当前账号已有任意邀约记录的达人，仅从无记录者建立队列；表单人数与任务总数按新候选计算，不把历史记录计为本次跳过。

采集列表、去重和发送记录按账号独立保存，每个账号只处理自己采集的达人。两平台均按平台、账号和达人 ID 排除已有邀约记录者，成功、跳过、失败、待核实和发送中记录都有效，不限日期。同一账号的采集和邀约可同时运行，底部主按钮只控制采集，邀约通过上方进度卡按账号停止。任务复制启动时的筛选、所选达人或配置并绑定账号；切换页面或账号不会改变运行中的任务。关闭软件停止任务，重启保留采集列表、进度和历史，不自动重发。

内置浏览器在平台页面加载前启用响应监听，只读取已适配的账号、额度、筛选及合作达人接口。筛选以当前路由最新请求的成功响应为准；换路由即清除上一页捕获，没有当前列表响应时等待网页筛选，失败、旧响应或任务自身请求不会覆盖网页筛选。其他页面显示「当前页面不支持采集」，开始采集不会自动跳转到固定页面。采集复用 60 秒内匹配当前筛选和页码的网页数据，过期时重新请求，并从第一页继续遍历；邀约在原网页环境内完成发送所需的联系人、账号、商品与佣金准备。

当前账号身份随成功响应更新；数据概览和账号列表中的额度来自平台网页被动观察到的响应，账号备注不被覆盖。快手只观察 `inviteType=1` 的 contact 额度，额度保留读取时间；启动、登录身份失效或变更、正式发送及额度周期结束后显示「待更新」，等待平台网页返回新额度。账号刷新、网页就绪和邀约任务均不主动查询额度，也不按本地剩余额度限制或扣减发送次数；发送接口返回额度不足时按邀约报错规则等待 10 秒重试。快手每次邀约任务通过 contact 请求取得发送必需的联系人字段，成功取得后复用，不从该请求读取额度。不同账号和不同网页的在途响应分别处理；登录窗口不改变采集条件，账号退出或变更会停止该账号任务。响应通过 document-start fetch/XHR 桥接观察，不依赖 Chrome DevTools。

## 登录数据

macOS 每账号使用独立 WKWebsiteDataStore 标识，Windows 使用独立数据目录；登录窗口与该账号工作页共用会话。网页的 Cookie、Local Storage 由系统 WebView 保存；登录 Cookie 快照写入应用数据目录的 `assistant-data/<账号标识>.session-cookies.json`，激活码写入 `license-tauri.json`，macOS 文件权限为 0600。登录失效时重新登录；平台接口确认身份后才显示已登录。

账号配置、采集列表、任务、邀约记录及日志保存在数据目录的 `assistant-data/assistant.sqlite3`。按批次和记录增量提交，列表由数据库筛选、排序和分页，概览直接读取汇总结果。首次启动自动导入原有本机运行数据和错误日志，原文件保留作备份；详见 [本地数据库](docs/DATABASE.md)。重启时发送中记录转为待核实，运行任务转为停止，不自动重发。

店铺 UUID、编号、名称与最近打开时间保存在 `assistant-data/workbench.json`，对应 Chrome 数据使用 `assistant-data/chrome-profiles/<账号 UUID>/`。账号列表和浏览器数据保留在本机，登录会话、收藏、标签页与扩展存储按账号隔离。关闭软件或安装更新时正常关闭浏览器；确认删除账号会关闭对应浏览器并删除该账号的浏览器目录，用户已下载文件保留。

视频插件只维护本仓库的 `browser-extension/`，版本与桌面端统一，开发启动、构建和打包时自动从 `package.json.version` 同步。插件随桌面安装包发布，正式运行按源码哈希同步到固定的 `assistant-data/browser-extensions/video-downloader/`。程序资源与账号数据分开，保留本机业务数据和下载文件，安装与资源详情见 [视频插件](docs/VIDEO_SOURCES.md)。

每个店铺复用固定的 Chrome 数据目录，缓存由该账号的 `Cache/` 保存。浏览器行为和视频解码能力随本机安装的 Google Chrome Stable，登录失效时在该账号窗口重新登录。

Google Chrome 使用本机安装位置，浏览器版本由 Chrome 自身更新。应用安装包保留桌面程序和视频插件资源，账号资料保存在各自的固定目录。

发送前先保存「发送中」记录。快手、抖音邀约准备或发送请求报错时，任务保持运行，等待 10 秒并满足本次配置的发送间隔后重试当前步骤或达人；复用同一条记录，不重复累计已处理、成功、失败或待核实数量。进度卡显示「邀约失败，10 秒后重试」；点击停止立即取消等待，已发出但未确定结果的请求保留为待核实，尚未发出的请求取消。授权失效及账号退出或身份变更仍停止任务；关闭重启不自动重发历史待核实记录，确认平台结果后可在记录详情人工核实。

日志和采集列表只清空当前账号，邀约记录可按当前筛选范围清空；清空记录会移除对应本地去重依据。当前账号正在运行采集或邀约任务时不可清空其采集列表；正在运行相关任务时不可清空邀约记录。Dialog、Sheet 与确认弹框只通过按钮关闭，点击空白或按 Esc 不关闭；主导航侧栏固定展开。

错误日志保存在本地 SQLite 日志表，不会被下一次任务覆盖；界面按当前账号从数据库分页查询，桌面端导出该账号的全部错误历史。正常采集进度也保存到日志表，按等级与错误记录区分；正常进度、成功、跳过及手动停止不作为错误日志显示。响应正文最多保留 8000 字并隐藏敏感字段，不记录请求 Cookie、联系方式或激活码。

## 检查与打包

测试与验收由用户负责。下列命令为手动入口，普通修改不自动执行测试、lint、构建或界面验收；用户要求打包或发布时，只执行该任务必需步骤。

| 命令 | 用途 |
| --- | --- |
| `pnpm lint` | 静态规则检查 |
| `pnpm build` | TypeScript 检查与前端构建 |
| `pnpm test:core`、`pnpm test:scripts` | 现有核心任务与脚本测试 |
| `pnpm test:native` | Rust `cargo check`，不代表真实平台验收 |
| `pnpm package:mac` | 在 Apple 芯片 Mac 打包 arm64 |
| `pnpm package:win` | 在 Windows x64 打包 |

Tauri 产物位于 `dist-release/tauri/<platform>/<arch>/`。Mac arm64 提供 DMG 和签名 app.tar.gz 更新包，Windows x64 提供 NSIS EXE。测试包与正式公证发布的区别见发布说明。

图标及导出方法见 [应用图标](assets/icons/README.md)：白底小虫、Mac ICNS、Windows 多尺寸 ICO，已接入窗口、Dock、网页和打包配置。通用激活码后台继续使用自己的名称和钥匙图标。

main / PR 的既有 CI 包含静态检查、Web 构建及核心、脚本、原生测试，不自动生成安装包。原生打包在手动发布工作流或版本 tag 工作流中执行，流程及所需 Secrets 见 [发布说明](docs/RELEASE.md)；普通修改不主动触发这些工作流。
