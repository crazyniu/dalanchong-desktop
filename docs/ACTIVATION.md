# 激活码接入

## 使用

1. 在 `license-admin` 后台选择「大懒虫」，软件标识必须是 `dalanchong`。
2. 创建所需时长的激活码，复制给用户。
3. 启动桌面端，输入激活码并点击「激活」。左下角「已激活 / 永久授权」只显示到期时间与设备码，不再提供激活码输入。
4. 换电脑时先在后台对该码执行「解绑换机」，再在新电脑激活。首次激活时间和原到期时间保留。

断网不能激活或使用受限功能，恢复联网后点击「重新验证」。后台解绑后不会自动重绑，需手动输入激活码激活。软件没有管理员登录入口，不需要管理员账号密码。

## 固定配置

- 软件：大懒虫
- `app_id`：`dalanchong`，沿用后台已有记录，不得改成包名。
- 接口：`https://lfrgswefkgdzhureqzod.supabase.co/functions/v1/license-api`
- `POST /activate`、`POST /verify` 请求体：`{ app_id, code, device_id }`。
- 公共接口不需要 Supabase 管理员凭据或服务端密钥；详细协议见 [授权接口文档](https://github.com/crazyniu/license-admin/blob/main/docs/API.md)。

## 运行流程

`LicenseGate` 启动时请求 `verifyLicense()`，成功后才载入业务数据与页面。未激活、过期、设备被禁用、设备不符或联网失败时显示激活页。

主进程 `handle()` 默认在执行业务 IPC 前调用 `/verify`。`getConnection()` 返回的任务 API 在每次平台请求前再次校验，覆盖长时间采集与邀约任务；停止任务不受授权限制。校验失败抛出 `beforeSend` 错误，任务停止，不把尚未发出的邀请标记成已发送或待核实。在途平台请求可能已完成，沿用任务原有结果处理。

闲置时不轮询；过期或后台解绑在下一次业务操作或任务请求前生效。退出重启只校验，不重新激活或续期。校验失败不会自动调用 `/activate`。

激活码只在成功激活后保存。输错替换码保留旧码。设备码为主进程提供的持久化安装 ID；断网也能查看和复制。授权时间取服务端返回值，界面按本地时区显示，永久授权的 `expires_at` 为 `null`。

## 本机数据

`<Electron userData>/assistant-data/license.json` 保存随机安装 UUID 和 safeStorage 加密后的激活码，文件权限 `0600`。不保存可作为离线授权依据的成功状态，渲染进程不读取明文码。

`sh ./run.sh` 默认使用 `../.local/ecommerce-assistant`，与已有账号数据共用同一目录。单独 `pnpm desktop` 沿用 `<appData>/电商助手` 目录（旧名称用于保持数据兼容）；两种方式的安装 ID 不同，请日常统一用 `run.sh`。清空目录或换数据目录会成为新设备。安装 ID 是本机持久化标识，不是硬件指纹；不要把用户数据目录复制给其他人。

浏览器 `pnpm dev` 是原有演示模式，无真实平台 IPC，不接授权。Electron 开发和生产构建均启用授权，不能用环境变量跳过。

### 界面更新

应用名称改为「大懒虫」，`app_id` 仍为 `dalanchong`。激活前设备码通过只读 `getLicenseState()` 取得，无须联网；启动联网校验期间不要求重新输入激活码。有效授权窗口只显示到期时间、设备码和复制按钮。已用临时码检查两种界面与复制反馈，临时码已清理。

后台可按软件禁用设备，服务端返回 `device_disabled`，桌面提示「此设备已被禁用，请联系管理员」。下一次业务校验即拒绝；更换激活码或解绑不会解除禁用，恢复设备不延长有效期。后台只记录成功激活/校验的网络出口 IP（最近 20 个聚合记录）。
