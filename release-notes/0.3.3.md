## 新增功能

- 激活失败时可「复制错误详情」，包含请求时间、软件版本、接口、失败阶段及实际返回的状态和请求标识，不包含激活码、设备码或请求内容。

## 问题修复

- 激活与授权校验统一使用自定义域名 `https://dabudian.top`，由服务端转发至授权服务。
- 授权错误区分网络连接失败、HTTP 服务异常和响应格式异常，避免统一显示为网络错误。

本版提供 Windows x64 和 Apple 芯片 Mac arm64 安装包。

Mac 构建不使用 Developer ID 签名或公证，Windows 安装包无代码签名；保留现有 Tauri 更新签名。

未进行安装、升级及真实用户网络环境验收，尚未确认用户此前激活失败的具体原因。
