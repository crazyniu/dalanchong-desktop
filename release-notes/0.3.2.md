## 新增功能

- 新增「多店铺」，使用本机安装的 Google Chrome Stable，各店铺独立保存登录会话、标签页、收藏和插件数据；支持新建、改名、打开和删除。
- 多店铺自动加载视频插件，提供抖音视频列表、批量复制与下载，以及已适配罗盘、百应页面的视频操作。
- 新增「使用教程」和六步新手引导，首次进入时展示，可随时从教程页重播。
- 抖音与快手达人邀约使用独立侧栏入口，各平台通过账号 Tab 管理网页、登录会话和任务。
- 采集、邀约记录、任务和日志使用本地 SQLite 增量保存；列表分页、筛选和数据概览统计由数据库查询。

## 问题修复

- 邀约前按平台、当前账号和达人 ID 排除已有任意邀约记录的达人，不限记录日期或状态；批量与勾选邀约均从无记录者建立队列，表单人数和任务总数只计新候选，旧记录不计入本次跳过。
- 快手邀约间隔最低为 2 秒。正式发送返回 `400010` 时，等待 5 秒并满足用户配置的间隔后重试当前达人，复用同一记录且不重复计数；停止按钮可立即取消等待。其他不确定结果仍保留待核实并停止。
- 仅采集时显示网页任务遮罩；邀约期间网页保持可交互，进度和停止操作持续可用。
- 数据概览的邀约结果图仅显示成功、跳过、失败和待核实，中心总数与四种结果一致；已采集达人按当前保留列表及采集日期统计。
- 剩余额度使用平台网页被动返回的数据，按平台额度周期显示有效状态；邀约任务不主动查询或按本地额度扣减发送次数，额度不足以发送接口结果为准。

本版构建产物包含 Windows x64 和 Apple 芯片 Mac arm64 安装包，由 GitHub Actions 生成。

Mac 构建不使用 Developer ID 签名或公证，Windows 安装包无代码签名；打包保留现有 Tauri 更新签名流程。未进行真实商家账号的采集、邀约及线上升级验收。
