## 问题修复

- 抖音、快手邀约准备或发送请求报错后，任务保持运行，等待 10 秒重试当前步骤或达人；支持抖音环境风险提示、快手风控、额度不足及网络异常，仍遵守更长的用户发送间隔。
- 重试复用同一条邀约记录，不重复累计处理或成功数量；等待期间可立即手动停止，已发出但结果不确定的请求保留为待核实。
- 平台网页异常时保留邀约任务的等待重试，授权失效、账号退出及身份变更仍停止任务。

本版提供 Windows x64 和 Apple 芯片 Mac arm64 安装包。

Mac 构建不使用 Developer ID 签名或公证，Windows 安装包无代码签名；保留现有 Tauri 更新签名。

未进行安装、升级及真实平台邀约验收，由用户测试。
