## 新增功能

- 桌面端改用 Tauri 2 和系统浏览器内核，减少安装包体积。
- 账号使用独立的持久网页登录数据，保留先采集、再从采集列表选择达人邀约的流程。
- 更新改为签名校验，继续显示 Gitee Release 的中文新增功能和问题修复。

## 问题修复

- 替换原 Electron 窗口与请求监听，移除对象销毁时触发的 Electron 主进程异常路径。
- 平台页面的新窗口链接在当前账号会话中打开，修复工作台入口无响应的问题。
- 弹窗和下拉菜单显示时暂时隐藏内嵌网页，避免被原生浏览器遮挡。

本版 macOS 最低版本为 14。旧版账号需要重新登录；激活码需要重新输入，设备码及原有记录保留。
