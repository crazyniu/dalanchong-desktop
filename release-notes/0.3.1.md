## 新增功能

- 桌面端替换为 Tauri 2，使用系统浏览器内核，显著减少安装包体积。
- 每个账号独立保存登录数据，会话 Cookie 采用加密快照，支持退出后恢复。
- 保留先采集、再从采集列表选择达人邀约的流程，以及网页上的半透明错误日志。
- 启动时自动检测更新，升级弹窗显示本版本的中文功能和修复说明，下载包使用签名校验。

## 问题修复

- 清理 Electron 运行代码、依赖、打包配置和专属旧测试，移除旧对象销毁异常路径。
- 平台工作台的新窗口链接在对应账号会话内打开。
- 修复原生网页遮挡弹窗、下拉菜单和日志的问题。
- 修复没有到期时间的 Cookie 在退出后丢失的问题。
- 修复输入无效激活码后设备码消失的问题。

本次为 macOS Apple Silicon 测试版本，最低 macOS 14，已进行本机 Developer ID 签名，未公证。Intel Mac 和 Windows 安装包不在本次测试发布范围内。

从 0.2.x 迁移需手动安装新版、重新登录账号并输入原激活码；设备码和运行记录保留，旧账号备注与邀约配置需重新填写。未使用真实商家账号测试邀约发送。
