## 新增功能

- 桌面端使用 Tauri 2 和系统浏览器内核。
- 每个账号独立保存登录数据，支持退出后恢复。
- 保留先采集、再从采集列表选择达人邀约的流程。
- 启动时自动检测更新，升级弹窗显示本版本的中文功能和修复说明，下载包使用签名校验。

## 问题修复

- 平台工作台的新窗口链接在对应账号会话内打开。
- 修复原生网页遮挡弹窗、下拉菜单和日志的问题。
- 修复没有到期时间的 Cookie 在退出后丢失的问题。
- 修复输入无效激活码后设备码消失的问题。

本次为 Windows x64 测试版本，由 GitHub Actions 构建；更新包使用固定 Tauri 密钥签名，安装程序尚无 Windows 代码签名证书。本次不构建或测试 Mac 版本。
